# Contributing

Thank you for helping make this guide better for students.

## Ways to help

- **Fix mistakes:** typos, wrong code, unclear explanations
- **Improve explanations:** a simpler analogy or a clearer diagram
- **Add practice problems:** with the pattern and difficulty level
- **Suggest topics:** open an issue describing what you'd like to see

## Guidelines

- Keep explanations simple. If a 17-year-old couldn't follow it, simplify it.
- Follow the page structure: one-sentence summary, "Picture it," diagram, code, practice, "Check yourself."
- Test any code you add.
- Only link to reputable resources, and prefer free ones.
- Diagrams use [Mermaid](https://mermaid.js.org), which GitHub renders automatically.

## How to contribute

1. Fork this repository
2. Create a branch: `git checkout -b improve-graphs-page`
3. Make your changes and commit them
4. Open a pull request describing what you changed and why
