# Resources

Free (or mostly free) resources chosen for beginners. Start with one from each section rather than trying all of them.

## Python foundations

| Resource | Why it's useful |
|---|---|
| [The Python Tutorial (official)](https://docs.python.org/3/tutorial/) | Clear, complete, free |
| [CS50x by Harvard](https://cs50.harvard.edu/x/) | The best free introduction to computer science |

## Data structures and algorithms

| Resource | Type | Why it's useful |
|---|---|---|
| [VisuAlgo](https://visualgo.net) | Interactive | Watch data structures and algorithms animate step by step |
| [Big-O Cheat Sheet](https://www.bigocheatsheet.com) | Reference | Complexities of common operations on one page |
| [NeetCode Roadmap](https://neetcode.io/roadmap) | Practice plan | Interview problems grouped by pattern, with video explanations |
| [LeetCode](https://leetcode.com) | Practice | The standard site for interview problems |
| *Grokking Algorithms* by Aditya Bhargava | Book | A friendly, illustrated introduction |
| *Introduction to Algorithms* (CLRS) | Book | The classic in-depth reference, for later |

## Machine learning and neural networks

| Resource | Type | Why it's useful |
|---|---|---|
| [3Blue1Brown: Neural networks](https://www.3blue1brown.com/topics/neural-networks) | Videos | Beautiful visual explanations, including transformers |
| [Google Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) | Course | Short, practical introduction to ML |
| [PyTorch Tutorials](https://pytorch.org/tutorials/) | Tutorials | Hands-on deep learning with the most popular framework |

## Large language models

| Resource | Type | Why it's useful |
|---|---|---|
| [Andrej Karpathy: Neural Networks, Zero to Hero](https://karpathy.ai/zero-to-hero.html) | Videos | Builds neural networks and a small GPT from scratch, in code |
| [The Illustrated Transformer by Jay Alammar](https://jalammar.github.io/illustrated-transformer/) | Article | The most famous visual explanation of transformers |
| [Hugging Face LLM Course](https://huggingface.co/learn/llm-course/chapter1/1) | Course | Free, hands-on course with the Transformers library |
| [Build a Large Language Model (From Scratch), code by Sebastian Raschka](https://github.com/rasbt/LLMs-from-scratch) | Book + code | Step-by-step code for building an LLM yourself |
| [DeepLearning.AI Short Courses](https://www.deeplearning.ai/short-courses/) | Courses | Short, practical courses on RAG, agents and fine-tuning |
| [Stanford CS224N](https://web.stanford.edu/class/cs224n/) | University course | NLP and deep learning in depth, for when you want more theory |
| [Lilian Weng's blog](https://lilianweng.github.io) | Articles | Deep, well-explained posts on LLMs and agents |
| ["Attention Is All You Need" (2017)](https://arxiv.org/abs/1706.03762) | Paper | The paper that introduced the transformer |

## Building with LLMs

| Resource | Why it's useful |
|---|---|
| [Prompt engineering guide (Anthropic)](https://docs.claude.com/en/docs/build-with-claude/prompt-engineering/overview) | Practical prompting techniques with examples |
| [Hugging Face PEFT documentation](https://huggingface.co/docs/peft) | LoRA and other efficient fine-tuning methods |
| [llm-gpu-memory](https://github.com/anjaliparihar97/llm-gpu-memory) | Measured GPU memory for quantization, batching, LoRA and QLoRA on a free GPU |

## A suggested 12-week plan

| Weeks | DSA | LLMs |
|---|---|---|
| 1 to 2 | Big-O, arrays, hashing | How LLMs work, embeddings |
| 3 to 4 | Linked lists, stacks, queues | Attention, transformers (3Blue1Brown, Illustrated Transformer) |
| 5 to 6 | Recursion, binary search | Training and gradients (Karpathy's first videos) |
| 7 to 8 | Trees, heaps | Prompting and RAG (build a small RAG app) |
| 9 to 10 | Graphs | Fine-tuning and LoRA (Hugging Face course) |
| 11 to 12 | Dynamic programming, mixed practice | Agents and evaluation (build a small agent) |
